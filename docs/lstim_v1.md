# LSTIM v1: Shared language and compiler contract

**Status (2026-11-08):** M8-A syntax, M8-B checking/lowering, M8-C public APIs and
M8-D independent physical/noisy simulation certification are implemented for the
[documented test matrix](lstim_certification.md). This tracked document is the
canonical contract for M8-A through M8-D. A successful
syntax-only parse still establishes no semantic or quantum-state validity.

**Repository:** `AKTKN/logical_to_stim_converter`. M8-A baseline is
`06cdc4fd61486cb4e0d138feff10c685bc1a0858` (M7-C, November 8, 2026).

## 1. Scope and invariants

LSTIM is a **logical** circuit DSL: it describes logical operations and explicit reservations of fixed physical code patches. It does not describe physical Stim gate layers or detector formulas. Parse LSTIM into the **existing** Python `OperationModule`/`BindPatch` program format, then use **the existing** `CircuitCompiler`, verified stimflow chunks, noise injection, canonical detector model, epoch-aware metadata, decoder views and frame plans. Do not implement an alternative physical compiler, decoder, simulator, implicit allocator, physical scheduler or adaptive-feedback engine.

The input must be independent of decoder selection and, by default, of the physical noise model. Supply `NoiseModel` when compiling. `knill_bench` owns sampling and decoding policies, not LSTIM or its converter runtime.

Keep the following identifiers distinct:

- Physical patch ID: permanent geometry and physical qubit sites, e.g. `P0`.
- Logical state handle: an occupant's name, e.g. persistent `D` or temporary `A1`. A retired logical handle cannot be rebound.
- `BlockUseId(P0, epoch)`: compiler-generated occupancy from actual `LogicalInit` reset until destructive readout. `BIND` does **not** increment epoch and cannot set it manually.
- Module ID: compiler-generated unique executed primitive.
- Optional **source operation label**: a user-assigned stable label passed as `operation_id` to the existing Python operation.
- Stage ID: semantic QEC protocol region generated by the existing planner, **not** a logical parallel layer or physical `TICK`.
- Global Stim raw measurement and detector indices: generated during physical assembly, never authored in source LSTIM.

`FORMAT(1)` is required as the first non-comment statement. All identifiers are ASCII and case-sensitive; their grammar is `[A-Za-z_][A-Za-z0-9_]*`. Define reserved words explicitly; disallow collisions with keywords where a free name is expected. `#` starts a comment through end-of-line. Blank lines, LF and CRLF are accepted. No arbitrary Python expressions, `eval`, dynamic imports or macro evaluation.

## 2. Concrete syntax examples

### Ordinary memory

```text
FORMAT(1)
CODE sc ROTATED_SURFACE(3)
PATCH P0 sc index=0
BIND D P0
INIT_Z(3) D
REPEAT 2 {
    SE(1) D
}
MZ D
```

### Three physical patches with explicit Knill reuse

```text
FORMAT(1)
CODE sc ROTATED_SURFACE(3)
PATCH P0 sc index=0
PATCH P1 sc index=1
PATCH P2 sc index=2
BIND D P0
BIND A0 P1
BIND B0 P2
INIT_Z(3) D
KNILL_EC[cycle0](3) D A0 B0
SE(1) D
BIND A1 P0
BIND B1 P1
KNILL_EC[cycle1](3) D A1 B1
SE(1) D
BIND A2 P2
BIND B2 P0
KNILL_EC[cycle2](3) D A2 B2
SE(1) D
MZ D
```

The user-authored `(D, A, B)` patch triples are `(P0,P1,P2)`, `(P2,P0,P1)`, `(P1,P2,P0)`. No compiler-driven patch selection, resource retry or resource-name reuse is permitted. `D` survives each teleportation, while the temporary resource handles retire. The physical wires are fixed; the reset operations generate the actual epochs.

### Logical parallel layer

```text
PARALLEL {
    SE(3) D
    SE(1) A
}
```

This lowers to a **single tuple/list of disjoint existing Python operations**, with no physical `TICK` authored by the parser. Adjacent top-level lines are sequential logical barriers. The existing compiler determines physical gate/TICK alignment and idle noise. In v1, `PARALLEL` contains only primitive operation statements, not nested `PARALLEL`/`REPEAT`, declarations or `BIND` (these remain sequential top-level directives).

## 3. Syntax and semantics table

| LSTIM | Existing Python lowering | v1 semantics |
|---|---|---|
| `FORMAT(1)` | source-version check | Exactly once, first non-comment statement |
| `CODE sc ROTATED_SURFACE(3)` | `CodeSpec.rotated_surface(3)` | Top-level code declaration |
| `PATCH P0 sc index=0` | `LogicalBlock.placed('P0', code, patch_index=0)` | Fixed patch; `index` required in v1 |
| `BIND D P0` | `BindPatch('D','P0')` | Sequential zero-duration reservation; NOT a reset |
| `INIT_Z(3) D` | `LogicalInit('D', 'Z', 3)` | Reset then 3 full SE rounds |
| `INIT_X(3) D` | `LogicalInit('D', 'X', 3)` | Reset then 3 full SE rounds |
| `SE(2) D` | `SyndromeExtraction('D', 2)` | 2 full SE rounds, not TICKs |
| `H D` | `TransversalH('D')` | Existing backend's physical logical H |
| `CX D A` | `TransversalCNOT('D','A')` | First is control, second target |
| `X D`, `Y D`, `Z D` | `LogicalPauli('D', axis, mode='physical')` | Physical encoded Pauli, default mode |
| `X D mode=frame` | `LogicalPauli(..., mode='frame')` | Zero-duration software frame update |
| `MX D`, `MZ D` | `LogicalMeasure('D', basis, mode='deterministic')` | Destructive readout; observable if deterministic |
| `MX D mode=random` | `LogicalMeasure(..., mode='random')` | Random readout; no asserted deterministic observable |
| `BELL_PREP(3) A B` | `BellStatePrep('A','B',3)` | A is X-initialized, B Z-initialized, encoded CNOT A->B |
| `KNILL_EC(3) D A B` | `KnillEC('D','A','B',rounds=3)` | One encoded teleportation, resource prep with 3 SE rounds |
| `KNILL_EC D A B prepare_resource=false` | `KnillEC(..., prepare_resource=False)` | Resources must already be prepared as an appropriate encoded Bell state |
| `KNILL_EC[tag](3) D A B` | `KnillEC(..., operation_id='tag')` | Stable source label, not a stage or epoch |
| `REPEAT N { ... }` | bounded static unrolling | `N` positive; see restrictions below |

For v1 `BELL_PREP` and `KNILL_EC`, a missing `(rounds)` lowers to `rounds=None`, retaining the existing Python default. For `KNILL_EC prepare_resource=false`, reject an explicit unused rounds argument rather than silently ignoring it. Accept `mode=physical|frame` only for Pauli instructions, `mode=deterministic|random` only for readout, and `prepare_resource=true|false` only for `KNILL_EC`. Do not interpret arbitrary key/value options or silently ignore unknown options.

Use the optional operation label `[name]` **before** `(rounds)` when both are present, as in `KNILL_EC[cycle1](3) D A B`. Labelled operations lower to existing `operation_id`; labels must be globally unique in the fully lowered program. The syntax `NAME(args) targets` is similar to Stim, but the source is **not** a Stim `.stim` circuit.

Physical `R`, `RX`, `TICK`, `DETECTOR`, `OBSERVABLE_INCLUDE`, `rec[-k]`, physical `DEPOLARIZE*`, arbitrary MPP, and decoder commands are **not supported** in LSTIM v1. Physical detector placement is the responsibility of the existing verified compiler.

## 4. Declaration, binding and repetition rules

- Exactly one `FORMAT(1)` header. `CODE` and `PATCH` statements are allowed **only before the first executable statement**, including the first `BIND`.
- A `PATCH` must reference a preceding `CODE`. All code aliases and patch IDs are unique. `index` is a nonnegative integer, unique among patch declarations for simple placement; physical-coordinate collisions are finally validated by `CircuitCompiler`.
- `BIND` is a runtime sequencing directive, allowed after declarations and between operations, preserving its exact order. The lowering must initialize `CircuitCompiler(blocks, logical_to_block={})` when using source `BIND` directives. Without this explicit empty initial mapping the current compiler implicitly reserves block-named handles and text BIND would collide. Never use default auto-reservation as a substitute.
- `PARALLEL` contains at least two ordinary operation statements on disjoint logical/physical targets. The existing compiler remains the authority for physical overlap and lifecycle checks. No nesting or BIND inside v1 PARALLEL.
- `REPEAT N` may contain ordinary *state-preserving* operations (`SE`, `H`, `CX`, `X`, `Y`, `Z`) and `PARALLEL` groups composed exclusively of these; nested `REPEAT` is allowed and statically unrolled. Disallow `INIT_*`, `MX`, `MZ`, `BIND`, `KNILL_EC`, `BELL_PREP`, declarations and explicit operation labels within any repeat in v1. These restrictions prevent implicit fresh logical names, unintended epoch changes and duplicate source labels.
- A REPEAT body must be nonempty. Together with positive counts and the minimum
  parallel size this prevents unbounded iteration of an empty body at zero cost.
- `REPEAT` does not imply compression into Stim `REPEAT` or one `SyndromeExtraction(N)` module. Unrolling means **N copies of the existing operations and their logical barriers**, including separate module/stage identities and correct per-module noise/provenance.
- Set a documented, tested upper bound on total expanded operation count (recommended default 100,000) and nesting depth; reject over-budget programs **before** materializing huge lists.
- All code/patch declarations and runtime statements are deterministic and immutable after validation. Preserve source file, line, column and spans on AST nodes for diagnostics. Generated physical artifacts are the same as equivalent direct Python assembly when using identical operation labels, explicit bindings, noise models and ordering.

## 5. Module responsibility boundaries

Suggested package layout (adapt conservatively to actual repository style):

```text
src/logical_to_stim_converter/language/
    __init__.py
    grammar.lark         # Single source of syntactic truth
    lexer.py             # Tokenization adapter using the same Lark grammar
    parser.py            # Token/parse-tree construction and syntax diagnostics
    ast_nodes.py         # Frozen typed nodes and SourceSpan
    transformer.py       # Lark parse tree -> typed AST
    semantics.py         # Static version/declaration/signature validation
    lowering.py          # Validated AST -> exact existing Python operations
    program.py           # LogicalProgram, compile bridge, user-facing contract
    formatter.py         # Canonical syntax; no semantic changes
    errors.py            # Syntax/semantic errors with source locations
```

The grammar is **one source of truth**: do not separately implement an incompatible regex parser. Lexer tokens may be based on Lark's contextual lexer; reserve regular expressions for lexical patterns such as names and integers. LALR + positional metadata is the initial parsing approach. AST types should not depend on Stim, stimflow, PyMatching or concrete decoders. Semantic analysis must not duplicate M7 physical lifecycle state machines; delegate the final quantum-state and flow validation to the existing compiler.

Public API (package root or language namespace):

```python
program = parse_logical_circuit(text, source_name='example.lstim')
compiled = program.compile(noise_model=noise, allow_open_outputs=False)
canonical_text = format_logical_circuit(program)
program_from_file = parse_logical_file('example.lstim')
```

Provide a second documented method/property to inspect the lowered `OperationModule`/`BindPatch` sequence and fixed `LogicalBlock`s without sampling or building a DEM. A text `BIND` must remain an existing `BindPatch` directive in that sequence. No independent decoder, CLI, hidden quantum feedback or new physical code-generation backend.

## 6. Validation expectations and future-proofing

- A valid syntax tree is **not** proof of a valid quantum circuit. Unknown operand, wrong code, pre-initialization gates, stale resource IDs, illegal rebinding, conflicting parallel physical patches, malformed Knill resource state, and signed-flow inconsistencies must fail using the existing compiler validation, with source context where feasible.
- Invalid header/version, unknown opcode, malformed arity, wrong option/value/type, reserved identifiers, declaration after execution, zero/negative rounds, duplicate IDs, unterminated braces, oversized repetitions and bad encoding must produce deterministic useful diagnostics.
- `format -> parse` preserves AST semantics, not necessarily comments/whitespace. Formatter must not reorder operations, change patch placement, change labels or alter the semantic meaning of repeat/parallel boundaries.
- Named labels feed existing `operation_id` and composite child metadata. At least retain source spans in the AST and provide a verified mapping for explicitly labelled operations. Do **not** invent a second planner to emulate implicit `moduleNNNN` numbering.
- Build one shared physical circuit with `CircuitCompiler`, then compare ideal/noisy Stim circuits, global DEMs, record/observable metadata, `BlockUseId` history, frame plans, and seeded raw samples to equivalent direct Python programs.
- Keep physical and decoding packages unchanged except for a minimal, well-tested integration hook. Update root and directory `AGENTS.md`, `STATUS.md`, README, architecture docs, grammar specification, and CI as appropriate; preserve all existing M1-M7 tests.

## 7. Frozen M8-A lexical and syntactic decisions

`language/grammar.lark` is the single syntax authority. It is loaded through
`importlib.resources` from either the source installation or a wheel. Tested
runtime: `lark==1.3.1`, LALR with contextual lexing and positional metadata.
`language.parse_ast(source, source_name='<string>')` returns a frozen FileNode
with a HeaderNode, ordered statements and SourceSpans. The limited internal
`lex_source` diagnostic API returns immutable tokens from the same contextual
parse; it also rejects invalid grammatical structure. No package-root public
program API is introduced in M8-A.

- The first non-comment statement is FORMAT(integer), exactly once. The integer
  is retained even if unsupported; semantic version rejection belongs to M8-B.
- Instructions occupy separate logical lines. A block's opening brace follows
  PARALLEL or REPEAT/count on that line; its contents begin on the next line.
  A closing brace occupies its own line. LF and CRLF are accepted, as are spaces,
  tabs, blank/comment-only lines, Unicode comments and EOF without a newline.
  Semicolons, bare CR line endings and line continuations are not supported.
- ASCII identifiers are case-sensitive `[A-Za-z_][A-Za-z0-9_]*`. Reserved words
  are FORMAT, CODE, ROTATED_SURFACE, PATCH, index, BIND, PARALLEL, REPEAT, INIT_Z,
  INIT_X, SE, H, CX, X, Y, Z, MX, MZ, BELL_PREP, KNILL_EC, true and false.
  They cannot be free names, option keys or labels. Keyword prefixes such as H2
  remain identifiers. Keywords cannot be split out of adjacent identifier text.
- Integers contain decimal digits only; leading zeroes are accepted and their
  numeric value is retained. Signs, floats, exponent notation and expressions
  are rejected. Distance, rounds, version and repeat count positivity/support
  remain semantic checks. PATCH index is syntactically nonnegative.
- Optional labels precede optional `(rounds)`, then one or more target names,
  then zero or more `key=value` options. A word followed by optional horizontal
  whitespace and `=` is lexically an option key, so LALR needs no ambiguous
  choice between one more target and the first option. A target cannot follow
  an option. Options preserve order and scalar string/int/bool types; unknown
  keys, duplicate keys, unsupported values, rounds and arities are checked by M8-B semantics.
- PARALLEL contains primitive operation lines only, with no nested groups,
  declarations, bindings or composites. REPEAT contains operation lines,
  PARALLEL groups and nested REPEAT. Empty blocks and resource-changing operation
  lines in REPEAT parse structurally; minimum cardinality and allowed repeated
  opcodes/labels/counts are semantic restrictions described in section 4.
  Top-level declaration ordering and name resolution are checked by M8-B semantics.
- Physical Stim instructions, raw record expressions, quoted strings,
  interpolation and executable expressions are outside the grammar.

SourceSpans use 1-based lines/columns and half-open ends. Character offsets refer
to Python code points in the original text, retaining CRLF. Offsets are excluded
from equality/hash so otherwise identical LF/CRLF trees compare equally; the
offset fields remain available for slicing each original source. Node spans
include punctuation, exclude surrounding indentation/trailing comments, and
include any interior comments/newlines. The FileNode span covers the whole input.
All source errors derive from LSTIMError. Located syntax and semantic errors carry
source_name, line, column, span, a bounded excerpt and caret. Lexical and parse subclasses distinguish
invalid input positions from invalid token order/EOF; contextual lexing can report
an unexpected character for an unavailable token. Ordinary errors are raised for
callers to catch and display, with raw Lark exception chaining suppressed.

Parser budgets are 1,000,000 source code points, 100,000 grammar tokens (including
newlines), 64 nested brace blocks, and 128 digits per decimal integer. Oversized
input raises a located LstimLimitError before AST construction. The transformer
is iterative and repeats are never expanded here. These syntactic budgets are
separate from M8-B's required expanded-operation budget (recommended 100,000).

## 8. Implemented M8-B semantic program

The root/language `parse_logical_circuit(source, source_name='<string>',
max_operations=100_000)` entrypoint returns an immutable LogicalProgram.
`program.ast` retains the unexpanded syntax; `source`/`source_name` retain the
original diagnostic input. `blocks` and `to_operations()`/`operations` are tuples
of actual existing LogicalBlock and OperationModule/BindPatch objects. Inspecting
them does not compile a physical circuit or build a DEM. No code/patch/operation
definition is a mutable per-shot context. Physical imports occur only when
lowering or compiling; syntax-only clients remain independent.

Validation enforces FORMAT(1), odd integer distance >=3, preceding code aliases,
unique aliases/physical patch IDs/placement indices, and declaration ordering.
Code aliases, physical IDs and logical handles remain separate namespaces. Every
operation target requires a preceding BIND introducing its handle. This tracks
name existence only: active/retired state, reservations, overlap, logical Bell
resources and basis determinism remain the existing compiler's responsibility.
Every unary v1 opcode (including SE/INIT) takes exactly one target; CX/BELL_PREP
take two distinct targets and KNILL_EC three. Existing Python multi-target APIs
remain unchanged; use explicit PARALLEL for v1 concurrent unary instructions.
Supported rounds/options/defaults and unique explicit labels follow section 3.
Unsupported physical/unknown command text fails in the syntax layer before
semantic analysis; manually supplied unknown AST opcodes also fail validation.
No epoch, module number or physical detector/record index can be overridden.

REPEAT accepts only unlabelled SE/H/CX/X/Y/Z operations and primitive parallel
groups of those, including nested repeats within the 64-block syntax bound.
Static cost sums all operation/directive occurrences, counts each parallel
member, and multiplies repeat costs with budget checks before materialization.
The default maximum is 100,000; max_operations can set another positive integer.
All static validation completes before constructing any code/patch definitions.
Each repeated operation is a separate existing object and barrier; SE(1) repeated
N times is not SE(N), and parallel groups are not flattened or sorted.

`program.compile(noise_model=None, allow_open_outputs=False)` instantiates
`CircuitCompiler(program.blocks, logical_to_block={})` and delegates exactly once
to its compile method. It returns the standard CompiledCircuit, including all
canonical detector/record/use/stage metadata and existing offline APIs. BIND
remains an existing directive with no reset/time/noise. The physical compiler
alone increments epochs at actual LogicalInit. Repeated calls with different
noise models construct independent artifacts and leave the source/program intact.

LSTIMSemanticError reports the offending source statement/option and its span.
LSTIMCompileError preserves the original validation exception in original_error
and __cause__. Current compiler errors expose no reliable source statement token;
the wrapper therefore sets span/line/column to None and reports the known file
and underlying reason. It never infers implicit module numbers from operation
counts or guesses a failing source line. `operation_spans` aligns with lowered
entries (nested tuples for parallel members); `label_spans` maps explicit source
labels to their statement spans. Existing operation_id and composite_ids preserve
these labels in successful compiled metadata, including labelled Knill children.

M8-B certifies focused exact physical/DEM/metadata equivalence against independent
Python references and unchanged compiler validation. M8-C adds the package-root
parser, parse_logical_file, canonical formatter and installed public interface.
M8-D verifies exact raw samples, decoder predictions, corrections, frames and
failure/LER equivalence on the documented memory/three-patch matrix, using
independently authored references and shared physical samples. No CLI, implicit allocator, physical
scheduler, decoder, simulator or alternate physical compiler is introduced here.

## 9. Public files, canonical source and installation

Root and language export LogicalProgram, parse_logical_circuit, parse_logical_file,
format_logical_circuit and LSTIMError/LstimSyntaxError/LSTIMSemanticError/
LSTIMCompileError/LSTIMFileError. Syntax-only parse_ast/lex_source remain in the
language namespace. See the [concise usage/physical-meaning guide](lstim.md).

parse_logical_file accepts str or PathLike[str], reads strict UTF-8 and preserves
the supplied path as source_name, including Unicode names. It preserves original
CRLF offsets. OSError/UnicodeDecodeError are retained as original_error and
__cause__ on LSTIMFileError. Invalid UTF-8 reports the byte offset and a reliable
line/character column after the valid prefix; unreadable files have no guessed
line. It accepts the same max_operations keyword as text parsing.

format_logical_circuit accepts LogicalProgram or FileNode. It preserves every
typed field except SourceSpan: header version, code alias/family/distance,
patch ID/code/index, binding order, opcode/target order, explicit rounds, ordered
options and their scalar types, labels and nested repeat/parallel structure.
No defaults are inserted. Raw ASTs receive static validation under the default
expansion budget; programs retain any larger caller-validated budget. Grammar
reparsing and an exact immutable semantic signature prevent malformed names or
injected statements from being emitted as verified source. No lowering or
physical compilation runs. Formatting drops comments/blank lines and uses four
spaces per block, lowercase booleans, LF and exactly one final newline. It is
deterministic and idempotent; source spans naturally change after formatting.

Lark 1.3.1 is a required runtime dependency; grammar.lark is loaded through
importlib.resources and included in wheel and sdist. The wheel has no dependency
on examples/tests/reference clones, PyMatching or Matplotlib. Source distributions
include both exact samples from section 2 under examples/lstim/. Portable
isolated-wheel tests build a wheel from the sdist and compile both samples through
the root API, checking real metadata/DEMs, source labels and independent noise.
CI runs these checks on Ubuntu/Windows with Python 3.11/3.12; actual local and
remote evidence is distinguished in STATUS.md. The [development guide](development.md)
records dependency pins and the eight-worker pytest-xdist invocation.

## 10. Physical and simulation certification

The [M8-D evidence guide](lstim_certification.md) pairs source with explicit
Python references and reports actual Stim/DEM/decode statistics. The tests compare
exact circuits and DEMs, signed flows, all public canonical metadata, epochs,
bindings, Bell windows, source fingerprints and decoder-view global/local maps.
SourceSpan is frontend provenance only. Exact reference metadata requires the
same authored BIND sequence, labels and initial empty logical mapping; a legacy
runner's implicit initial reservations are not silently equated to source BINDs.

Separate same-seed samplers match bitwise for identical experiments. Offline
ordinary-memory and Knill decoding then consume shared raw records with quantum
execution prohibited. Equality includes ordered causal stage inputs, sectors,
corrections, interpreted records, physical X/Z frames, failure vectors, counts
and LER. Batch slicing and replaceable external adapters are checked. Independent
tableau/Bell-branch/reference and physical fault tests remain mandatory; decoder
agreement alone does not establish physical correctness. Supported scope is the
explicit matrix, with finite seeded batches and the existing restricted decoders.
