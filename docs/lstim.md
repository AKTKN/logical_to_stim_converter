# LSTIM v1 usage

LSTIM `.lstim` files describe logical operations and explicit patch reservations.
The compiler produces physical Stim circuits, detector/observable metadata and
offline decoder inputs. Sampling and decoder selection belong to the caller.
The direct Python operation-object API remains available.

```python
from logical_to_stim_converter import (
    NoiseModel, parse_logical_circuit, parse_logical_file, format_logical_circuit,
)

source = """FORMAT(1)
CODE sc ROTATED_SURFACE(3)
PATCH P0 sc index=0
BIND D P0
INIT_Z(3) D
REPEAT 2 {
    SE(1) D
}
MZ D
"""
program = parse_logical_circuit(source, source_name="memory.lstim")
print(format_logical_circuit(program))
compiled = program.compile(noise_model=NoiseModel.uniform_depolarizing(0.001))
compiled.validate_metadata()
view = compiled.make_decoder_view()
frame_plan = compiled.make_frame_plan()
# Sample files are included in the checkout/sdist, rather than required at runtime.
from_disk = parse_logical_file("examples/lstim/memory_d3.lstim")
assert from_disk.to_operations() == program.to_operations()
```

The root and `logical_to_stim_converter.language` export the same API.
`program.ast`, `blocks`, `operations`/`to_operations()`, `operation_spans` and
`label_spans` are read-only. Parsing performs static validation and bounded
lowering; it does not compile or sample. `compile` returns the ordinary
`CompiledCircuit`, with sampling, views, frame/stage requests and conditional
Bell models unchanged. Each call owns independent compilation state and may use
a different NoiseModel. Repeats statically unroll before the existing compiler;
the default budget is 100,000 operations/directives, adjustable with
`max_operations` on text/file parsing. Syntax-only `language.parse_ast` checks
grammar without establishing static or quantum validity.

| Source term | Physical meaning |
|---|---|
| `CODE sc ROTATED_SURFACE(3)` | Mathematical distance-3 code; no physical placement or noise |
| `PATCH P0 sc index=0` | Fixed physical block, coordinates and local qubit sites; index is explicit |
| `BIND D P0` | Reserve that patch for logical state handle D; no reset, duration or noise |
| LogicalStateId | The logical state's identity; D survives teleportation onto a different patch |
| BlockUseId / epoch | A physical occupancy beginning at an actual INIT reset; the compiler assigns it |
| Stage | A compiler-generated semantic QEC region, separate from labels, epochs and layers |
| `PARALLEL { ... }` | One logical layer of at least two primitive/composite operations; the compiler checks physical disjointness |
| Physical `TICK` | Gate/idle/noise time boundary generated by the physical compiler, never written in LSTIM |
| `INIT_Z(3)` / `SE(3)` | Reset then three full syndrome rounds / three full rounds without reset; rounds are not TICKs |
| `MX` / `MZ` | Destructive logical readout; deterministic by default, `mode=random` omits a deterministic observable |
| `KNILL_EC D A B` | Teleport D using encoded Bell resources A/B: consume old D and A, retain D's identity on B |

`BELL_PREP A B` prepares X on A and Z on B, followed by encoded CNOT A->B.
KNILL_EC normally prepares those resources; with `prepare_resource=false`, the
caller must have supplied the appropriate Bell state and must omit rounds.
Fresh handles reserve explicitly selected retired patches; source never assigns
epochs or chooses patches automatically. See the
[three-cycle source](../examples/lstim/three_patch_knill_d3.lstim).

Use `KNILL_EC[cycle2](3) D A B` to give an operation an explicit label.
`program.label_spans["cycle2"]` locates its source statement. The label becomes
the existing operation_id, visible through compiled composites and their child
fragments' composite_ids. Implicit module IDs have no guessed source lookup.
Labels must be unique and cannot occur inside REPEAT.

Formatting accepts a program or FileNode, validates source semantics and retains
declaration, binding, target, option and nested-group order. It drops comments and
blank lines and uses four spaces, lowercase booleans, LF and one final newline.
Defaults stay implicit. Malformed or statically invalid ASTs raise errors;
formatting does not prove physical lifecycle or stabilizer-flow validity.

Catch `LSTIMError` for all ordinary input failures, or distinguish:

- `LstimSyntaxError`: grammar/character/budget errors, with file:line:column.
- `LSTIMSemanticError`: invalid version, declaration, name, signature or option,
  with the offending statement/option span and valid alternatives where applicable.
- `LSTIMFileError`: unreadable path or invalid UTF-8, retaining original_error and
  __cause__; encoding errors report byte offset and line/character column.
- `LSTIMCompileError`: existing physical lifecycle/geometry/flow failure,
  retaining original_error and __cause__. The compiler supplies no reliable
  source statement marker, so this error reports the file without a guessed line.

Display `str(error)` for a bounded message/excerpt/caret. Files accept LF or CRLF
and Unicode UTF-8 comments; identifiers remain ASCII and case-sensitive.

The [v1 opcode/default table and grammar contract](lstim_v1.md) lists all accepted
forms. Physical Stim instructions, arbitrary expressions, runtime branching,
automatic patch allocation, text-defined noise/decoders, non-Clifford gates,
other code families and a CLI remain deferred. M8-D certifies the
[documented physical/noisy E2E matrix](lstim_certification.md) against independent
Python programs and unchanged external decoder adapters. Existing physical checks
remain in force; finite Monte Carlo agreement does not prove decoder optimality.
